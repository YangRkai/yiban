# 数目 / 数子

棋盘右上角的同一个按钮支持两种操作：

- 点一下显示，再点一下隐藏。
- 按住超过约 0.35 秒临时显示，松开隐藏。长按不会再触发单击；移出按钮会取消本次按压。

首次显示需要加载内置 CPU 模型并估算。若松开时还没有算完，结果到达也不会自动弹出；再次显示同一局面可使用缓存。下棋、悔棋或重新导入后，旧标记立即清除，显示状态开启时自动重算。

黑白方块表示预计归属，灰色菱形表示尚未确定。统计中的“归属点数”按标记逐点相加，包含本方棋子、空点和疑似对方死子。未确定位置不会被强行分给任何一方，预测为对方归属的棋子不会同时算给双方。

采用中国规则，白贴 7.5 目。引擎显示的领先目数已经包含贴目，不应再次加减；它是搜索估计，不能用阈值化后的归属点数简单相减来替代。这里的“空点”也不是日本规则下包含提子等调整的正式数目结果。

所有显示均为估算，包括双方停一手后的局面。终局仍需要确认死活；本功能不会删除棋子、自动判胜负或改变当前对局。

实现使用 [KataGo Analysis Engine](https://github.com/lightvector/KataGo/blob/master/docs/Analysis_Engine.md) 的 `includeOwnership`，固定黑方视角。数据从左上到右下按行映射；归属值 ≥ 0.65 标黑、≤ -0.65 标白，其余保留未确定。0.65 是显示阈值，不是统计置信区间。
