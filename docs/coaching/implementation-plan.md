# 每局一题实施计划

目标：离线 CPU 完成自动记录、单个有复核证据的问题、独立重试、合法变化演示及隔日原题复测。原题复测不能证明迁移能力，不宣称掌握。

架构：主程序保存 PVE 活动棋谱；教学窗口独立进程分析完整历史，不更改对局。先小预算筛查，再对推荐与实战着分别约束首手进行相同预算比较，两轮预算都支持才出题。仅描述数值和已验证变化，不生成未经验证的棋理原因。

任务：
- [x] 测试与实现原子存储、重复记录去重、复测记录与分数视角。
- [x] 实现 KataGo JSON 分析、取消、有限预算复核、GTP 合法变化演示。
- [x] 接入每局一题窗口、重试、显示答案、次日复测及 AI 导出。
- [x] 真实 CPU 测试、回归测试、安装包启动验证、发布。

边界：先支持当前本地 PVE 以及已保存的题目。执子或初始摆子变更时分段，首版不分析有初始摆子/中途换边的片段。不存在足够证据时显示没有找到可复核题目。新手强度调整另行验证，不能把这版称为已经实现自适应陪练。

验证：59 项本机测试通过；0.3.0 全新安装后的 CPU 教学流程及导出证据检查通过。尚未测量真实用户学习收益；不宣称类似局面迁移能力。
